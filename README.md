- サポート：https://nbashohei.github.io/smartcreca-info/

- 対象：SmartCreCa 2.0以降
- 公開方式：GitHub Pages / `main`ブランチのルート

HTMLとCSSだけで構成し、外部フォント、JavaScript、アクセス解析は使用していません。内容を変更する場合は、アプリのデータ処理と外部SDKの仕様に照らして確認し、ポリシーの更新日も更新してください。
